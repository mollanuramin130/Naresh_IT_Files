Que 1 :
=======

Write a C program to search user given element in an array and print its index. 
The program should prompt the user to input the element they want to search in array.
- If the element is found in the array, the program will print the index of the element. 
- If the element is not found, the program will display a message indicating that the element is not present in the array.
- Read the size and elements of the array from the user
- Check if the size of the array is negative, and print an Invalid message.

Example 1:

input :
	Enter array size : 9
	Enter 9 Elements : 3 8 4 1 9 5 9 8 9
	Enter Element to search: 7
output :
	Element 7 not found in the array

-------------

Example 2 :

input :
	Enter array size : 9
	Enter 9 Elements : 3 8 4 1 9 5 9 8 9
Element to search: 9
output :
	Element 9 found at index 4
-------------

Example 3 :

input :
	Enter array size : -5
output :
	Invalid size

Que 3 :
=======
Write a C program that finds and prints all pairs of numbers from a given array whose sum is equal to a specified target value. 
The program should iterate through the array, compare every pair of numbers, and print each pair that meets the condition.
- Read the size and elements of the array from the user
- Read the Target sum  from the user
- Check if the size of the array is negative, and print an Invalid message.

Example 1:

input:
	Enter array size : 5
	Enter 5 Elements : 1 5 7 -1 5
	Enter target Sum: 6

Sample output:
	Pair found: (1, 5)
	Pair found: (7, -1)
	Pair found: (1, 5)

--------------

Example 2:

input:
	Enter array size : 9
	Enter 9 Elements : 3 2 4 1 6 5 9 8 7
	Enter target Sum: 10

Sample output:
	Pair found: (3, 7)
	Pair found: (2, 8)
	Pair found: (4, 6)
	Pair found: (1, 9)

--------------

Example 3 :

input :
	Enter array size : -7

element - 0 : 25
