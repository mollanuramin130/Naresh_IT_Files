Que 1 :
=======

Write a C program that reads an integer from the user and prints the count of digits in the given number using while loop & defined function. 
The program should handle both positive and negative numbers.
create one user defined function and perform logic
function name :  countDigit()
parameter : int num
 

Example :

Sample input1  : 12348
Sample output1 : 5


Sample input2  : -129
Sample output2 : 3

Sample input3  : 0

Que 4 :
=======

Write a C program that reads a positive integer N from the user and calculates the sum of even and odd numbers between 1 and N using a while loop & defined function. 
The program should then print the sum of even numbers and the sum of odd numbers.

NOTE : If user entered negative input then print "Invalid Input" message.
create one user defined function and perform logic
function name :  oddEvenSum()
parameter : int num


Example_1 :

Sample input  : N = -10;

Sample output : Invalid Input


Example_2 :

Sample input  : N = 10;

Sample output : even sum => 2 + 4 + 6 + 8 + 10 = 30 
                odd sum  => 1 + 3 + 5 + 7 + 9 = 25
