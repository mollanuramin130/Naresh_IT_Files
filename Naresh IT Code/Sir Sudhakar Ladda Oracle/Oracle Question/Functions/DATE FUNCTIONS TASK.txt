10.Calulate age( in the form of years and months) of kiran. if dob of
   kiran is 31-DEC-1997?

SOLUTION:
===================================================================
SQL> SELECT TRUNC(MONTHS_BETWEEN(SYSDATE,'31-DEC-1997')/12) AS YEAR ,
     TRUNC(MOD(MONTHS_BETWEEN(SYSDATE,'31-DEC-1997'),12)) AS MONTHS FROM DUAL;

     27         1

DATE FUNCTIONS:-In oracle by default date format is DD-MON-YY
==============

   oracle having following predefined date functions.these
are

1.sysdate
2.systimestamp
3.add_months()
4.last_day()
5.next_day()
6.months_between()

1.sysdate :-it returns current date of the system in oracle 
==========     date format.

1.Write a query to display current system date?

SQL>select sysdate from dual;


      SYSDATE
     ---------
     02-JAN-25    


2.systimestamp:-it returns current date of the system and time

2.Display the current system date and time?

SQL>select systimestamp from dual;


          SYSTIMESTAMP
  -----------------------------------
  02-JAN-25 11.33.06.283000 AM +05:30




3.last_day():-it returns last date of the specified month with in 
============   given date.

3.Find the last date of the current month?

SQL>select last_day(sysdate) from dual;


      LAST_DAY
      ---------
      31-JAN-25


4.Find the last date from given date 16-APR-2024?

SQL>select last_day('16-APR-2024') from dual;


      LAST_DAY
     ---------
     30-APR-24


5.Find next month first date?

SQL>select last_day(sysdate)+1 from dual;


    LAST_DAY
    ---------
    01-FEB-25


6.Find current month 1st date?

SQL>select last_day(add_months(sysdate,-1))+1 from dual;


    LAST_DAY
   ---------
   01-JAN-25


4.next_day():-it is used to get next date based on the week day
============

7.Find next friday date

SQL> select next_day(sysdate,'fri') from dual;


     NEXT_DAY
    ---------
    03-JAN-25


8.Find next month first sunday date

SQL>select next_day(last_day(sysdate),'sun') from dual;


     NEXT_DAY
    ---------
    02-FEB-25
