                       GROUP FUNCTIONS Task
                     =========================

1.find sum of salaries of all employees from emp table?

SOLUTION:
===============================================================
SQL> SELECT SUM(SAL) AS TOTAL_SALARY FROM EMP;

   TOTAL_SALARY 
_______________ 
          29025 


2.find sum of salaries of all managers from emp table?

SOLUTION:
===============================================================

SQL> SELECT SUM(SAL) AS TOTAL_MANAGER_SALARY FROM EMP WHERE JOB='MANAGER';

   TOTAL_MANAGER_SALARY 
_______________________ 
                   8275 


3.find  sum of salaries of  deptno 10,30 from table?

SOLUTION:
===============================================================
SQL> SELECT SUM(SAL) AS DEPT_10_AND_30_TOTAL_SALARY FROM EMP WHERE DEPTNO IN(10,30);

   DEPT_10_AND_30_TOTAL_SALARY 
______________________________ 
                         18150 


4.find average salaries of all employees from emp table?

SOLUTION:
===============================================================
SQL> SELECT TRUNC(AVG(SAL),2) AS "AVERAGE SALARY" FROM EMP;

   AVERAGE SALARY 
_________________ 
          2073.21 

SQL> SELECT ROUND(AVG(SAL),2) AS "AVERAGE SALARY" FROM EMP;

   AVERAGE SALARY 
_________________ 
          2073.21

12.Write a query to find the no of employees in 4th quarter?

SOLUTION:
===============================================================
SQL> SELECT COUNT(*) AS NO_OF_EMP_IN_4QTR FROM EMP WHERE TO_CHAR(HIREDATE,'Q')=4;

   NO_OF_EMP_IN_4QTR 
____________________ 
                   5 

SQL> SELECT COUNT(*) AS NO_OF_EMP_IN_4QTR FROM EMP WHERE TO_CHAR(HIREDATE,'Q')='4';

   NO_OF_EMP_IN_4QTR 
____________________ 
                   5 


Count(column name):- It counts number of not null values within
==================      a column. 

13.find how many employees are getting commission?
