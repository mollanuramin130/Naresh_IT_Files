                               JOIN TASK
                              ==============

JOINS:- Joins are used to retrieve data from single or 
======            multiple tables. 
 

.In all databases when we are joining 'n' tables then we must use 
 'n-1' joining conditions. 

.join condition decides which record in one table should joined
 with which record in another table.

1.Inner join:- This join also returns matching rows only. Here also
=============   joining conditional columns must belongs to same 
                data type. Whenever tables having common columns then
                only we are using this join. Inner join (9i) 
                performance is very high compare to oracle 8i 
                equi join.

      join write the queries by using inner join.no problem


USING ALIASNAMES JOINS:-
======================
   In oracle we can also use table aliasnames in joins. whenever joins
having aliasnames then those joins improves performance of the query
because those joins very fastly retrieve data from database.in this
case we must create table aliasnames in from clause and then only
we must use those aliasnames in place of table with in select list
and also with in the joining condition.
