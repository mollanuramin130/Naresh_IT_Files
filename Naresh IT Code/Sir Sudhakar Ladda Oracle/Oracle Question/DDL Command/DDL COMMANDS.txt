1.Create a STUDENT table with the following columns
----->SNO 
----->SNAME
----->GENDER
----->FEE
----->DOB

Solution:
--------------------------------------------------------------------
SQL> CREATE TABLE STUDENT (SNO NUMBER(3),SNAME VARCHAR2(30),GENDER VARCHAR2
(6),FEE NUMBER(8,2),DOB VARCHAR2(20));



2.What is the command to view the structure of the STUDENT table?

Solution:
--------------------------------------------------------------------
SQL> DESC STUDENT;



3.Insert records into the STUDENT table.

Solution:
--------------------------------------------------------------------
STATIC:

SQL> INSERT INTO STUDENT VALUES(001,'NUR AMIN MOLLA','MALE',28000.00,'30-12
-1996');

SQL> INSERT INTO STUDENT VALUES(&SNO,'&SNAME','&GENDER',&FEE,'&DOB');

4.Write a query to display all the records from the STUDENT table.

Solution:

8.Write a query to rename the column SNAME to NAME.

Solution:
--------------------------------------------------------------------
SQL> ALTER TABLE STUDENT RENAME COLUMN FEE TO FEES;

Table STUDENT altered.



9.Write a query to drop the STUDENT table.

Solution:
--------------------------------------------------------------------
SQL> DROP TABLE STUDENT;

Table STUDENT dropped.



10.Write a query to restore the STUDENT table.

Solution:
--------------------------------------------------------------------
SQL> FLASHBACK TABLE STUDENT TO BEFORE DROP;

Flashback succeeded.



11.What is the command to rename the table STUDENT to STUDENTDATA?

Solution:
--------------------------------------------------------------------
SQL> RENAME STUDENT TO STUDENTDATA;

Table renamed.



12.What is the command to permanently delete the data from 
   the table in the database?

Solution:
--------------------------------------------------------------------

SQL> TRUNCATE TABLE STUDENT;

Table STUDENT truncated.

16.Write a query to display EMPNO,ENAME,JOB,BASIC_SALARY,5% of HRA,10% of DA,5% of PF,5% of ESI then calculate GROSS_SALARY and NET_SALARY from EMP Table who are working as a "MANAGER".

Solution:
--------------------------------------------------------------------

SQL> SELECT EMPNO,ENAME, JOB,SAL AS BASIC_SALARY,SAL*5/100 AS HRA,SAL*10/100 AS DA,SAL*5/100 AS PF,SAL*5/100 AS ESI,SAL+SAL*5/100+SAL*10/100 AS GROSS_SALARY,SAL+SAL*5/100+SAL*10/100-SAL*5/100-SAL*5/100 AS NET_SALARY FROM EMP WHERE JOB='MANAGER';
