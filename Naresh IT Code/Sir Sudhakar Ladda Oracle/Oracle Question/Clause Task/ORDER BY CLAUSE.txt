5.Write the query to  display the emp_first_name and emp_last_name as 
  emp_fullname  and year of birth and 
 sort them based on their desending age.

NOTE:-By default Calender order is ascending order




emp_id        emp_first_name        emp_last_name     birth date
------      -----------------     --------------      ------------
  1            john                  doe               23-apr-1985
  2            jill                  davis             15-jun-1999
  3            jack                  Johnson           25-oct-1992
  4            james                 Wilson            12-sep-1983

SOLUTION:
===================================================================
SQL> SELECT EMP_FIRST_NAME || ' '||EMP_LAST_NAME AS EMP_FULL_NAME ,TO_CHAR(DOB,'YYYY') AS YEAR_OF_BIRTH FROM EMP_INFO ORDER BY DOB ;

________________ ________________

JACK JOHNSON     1992
