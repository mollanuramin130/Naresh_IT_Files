Q14) Which of these selection statements test only for equality?

a) if
b) switch
c) if & switch
d) none of the mentioned

Ans: b


Explanation:
The if statement can test for equality (==) as well as other relational conditions like <, >, <=, >=, !=, etc.
The switch statement, on the other hand, only checks for equality (==) between the switch expression and case values.
Therefore, the only selection statement that tests only for equality is switch.

Q18) WAP in java to print table of the given number (Number must be taken from Scanner class)

class Test 
{
	
	public static void main(String[] args) 
	{
		Scanner sc= new Scanner(System.in);
		System.out.print("Enter the table number : ");
		int number=sc.nextInt();
		
		for(int i=1;i<=10;i++) {
			System.out.println(number + " X "+i+" = "+number*i);
		}
		sc.close();
	}
}
